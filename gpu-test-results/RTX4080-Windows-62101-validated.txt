Focused controls
----------------
cs_imgatomic_ext failed on baseline and in an isolated rerun in each mode:
six sint words differed; word 32 was 0x0badf00d instead of 0x00000101.
With #1518, --filter cs_imgatomic passes all three cases (cs_imgatomic,
cs_imgatomic3d, cs_imgatomic_ext), 3/3 in native and emulated modes.
The fixture's old volume key missed the tagged whole-mip descriptor entry.

cs_texture_uav baseline and isolated reruns failed in both modes: first 1D texel
remained 0x11 instead of 0x3f9. The shader expects a tagged descriptor table,
but this bare-SPIR-V harness has no shader-library index, so the runtime's
plain default supplies no kind bits and the shader routes stores to fallback.

Same unpatched executable as baseline (SHA-256 verified):
  Default: FAIL in both modes.
  LEONIDA_DESCRIPTOR_TABLE=tagged: PASS 1/1 in both modes.
With #2261 and its test executable rebuilt:
  Default, override unset: PASS 1/1 in both modes.
  Forced LEONIDA_DESCRIPTOR_TABLE=plain: FAIL 0/1, native negative control.
Direct patched harness: 14 GPU cases passed, 10 compared with Windows WARP;
format/range/refusal checks passed. Descriptor-only CTest: 1/1 passed.
Intentional format-refusal diagnostics also occur in the passing run.

Reproduction
------------
Initialize the MSVC x64 environment and put the named shader tools on PATH.
cmake -S runtime -B runtime/build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo -DVulkan_INCLUDE_DIR=<pinned-headers>/include -DLEONIDA_REQUIRE_VULKAN=ON
cmake --build runtime/build --parallel 8 --target vk_harness vk_texture_test vk_sampler_test vk_compute_test vk_store_test vk_bindless_test d3d12_texture_uav_test

Process-local settings: LEONIDA_VK_DEVICE=4080; LLVM_MC=<llvm-mc.exe>;
VK_LOADER_LAYERS_DISABLE=~implicit~; DISABLE_RTSS_LAYER=1;
DISABLE_VULKAN_OBS_CAPTURE=1; LEONIDA_GPU_TEST_TIMEOUT=120;
LEONIDA_TEST_DIR=<local-scratch>; PYTHONUNBUFFERED=1; PYTHONIOENCODING=utf-8.
LEONIDA_W64_EMULATE=0 for native, 1 for emulation; separate work folders per run.
python -u -I scripts/run_gpu_tests.py --build runtime/build --work <per-run-work> --assembler spirv-as --require-pass
For the focused cases, add --filter cs_imgatomic or --filter cs_texture_uav.
ctest --test-dir runtime/build -C RelWithDebInfo -R '^d3d12_texture_uav$' --output-on-failure
